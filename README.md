# Superstore Sales Analysis | Power BI

## Project Overview
This project analyzes Superstore sales data using Microsoft Power BI to understand sales performance, profitability, regional performance, and customer segments.

## Tools & Technologies
- Microsoft Power BI
- Power Query (Data Cleaning and Transformation)
- DAX (Data Analysis Expressions)
- Data Modeling and Visualization

## Dataset
- Orders: 9,994 records
- Returns: 296 records
- People: Regional manager information

## Data Preparation
- Checked and handled missing values and errors.
- Removed duplicate records where appropriate.
- Corrected data types.
- Applied Trim and Clean transformations.
- Validated order and shipping dates.
- Created a separate Date Table.
- Established relationships between tables.

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Total Customers

## Dashboard Analysis
- Sales by Region
- Sales by Category
- Sales by Customer Segment
- Profit by Category and Segment
- Year-wise filtering

## Business Insights
- Furniture profitability varies across years, with losses observed in certain periods in certain segments.
- Sales performance differs across regions and customer segments.
- Category-wise and segment-wise profit analysis helps identify stronger and weaker areas of business performance.

## Objective
To transform raw sales data into meaningful business insights through data cleaning, data modeling, DAX calculations, and interactive visualizations.
